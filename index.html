Time Looper（TL）— 指定した時間を繰り返す、楽器演奏ルーパー

使い方と、Driveリンクの注意点
  • 曲を足す：「曲」モードの「曲の追加」タブで、YouTubeのURL貼り付け／MP3ファイルを選ぶ／Driveの共有リンク貼り付け、の3通りから追加できます。YouTubeは、曲名やアーティスト名で検索して、結果の一覧から選んでそのまま追加・再生することもできます。
  • クイックキャプチャ（かんたんループ作成）：プレイヤーの操作ボタン列やループリスト上部の「クイックキャプチャ」の「10秒間」を押すと、押した瞬間を開始時間に、10秒あとを終了時間にしたループが、「今までの10秒間」を押すと、押した瞬間の10秒前を開始時間に、押した瞬間を終了時間にしたループがそのまま保存され、すぐ再生が始まります。ループは今の再生倍率で保存されます。キャプチャの秒数は固定ではなく、管理画面の「設定」タブで5秒／10秒／15秒／20秒のプリセットか、任意の秒数の入力（1〜120秒）で変更できます（設定は保存され、次回も使えます）。旗で細かく決める前に、まず大まかに繰り返したいときにおすすめです。ループ作成は「🎤 キャプチャ」ボタン1つにまとまっています：短くタップすると開始→終了・保存のトグルになり、長押しすると押している間だけがループ区間になって、離した瞬間に今の再生倍率で保存し、すぐ再生します（長押しの判定時間＝初期0.3秒＝より短い押下はホールドではなくタップとして扱われます）。曲の切り替えは「曲」モードのセットリストから行います（プレイヤー上部のセットリスト情報に、前／次の曲名が「曲名 / バンド名」で表示されます）。ループの状態ボタンは操作ボタン列の最後にあります。再生速度は、操作ボタン列の下・全体表示（タイムライン）の上にコンパクトに表示され、プリセットのボタン（初期は0.50×／0.75×／1.00×）か、フェーダー（25%〜200%、つまり0.25〜2.00×）でその場で変えられます。右側カードの再生速度欄にも同じボタンとフェーダーがあります。⏪／⏩のジャンプ秒数（初期10秒）、表示する倍率ボタン、長押しの最小時間などは、管理画面の「設定」タブで変更できます（設定は保存され、次回も使えます）。
  • ループ練習：「🎤 キャプチャ」ボタンをタップすると、その位置から再生が始まり、それまで設定されていた現在のループは解除されます（終了は外れ、新しい開始位置だけが残ります）。続けて同じボタンをもう一度タップすると、その区間を繰り返し、そのままループとして保存されます（別途「保存」を押す必要はありません）。作成されるループには「ループ1」「ループ2」のような名前が自動で付きます。名前は後から「編集」で変更できます。終了を押し直すと、保存済みの同じ区間の終了位置が新しい位置に更新されます。開始・終了位置は、時間の表示を押すと出てくる「<<< << < > >> >>>」ボタンで直せて（刻みは初期1秒／0.1秒／0.01秒、管理画面の「設定」で変更できます）、開始位置を変えると新しい開始位置から、終了位置を変えると終了の少し前（初期3秒前、「設定」で変更できます）から即プレビューします。決めた区間は何個でも保存できます。ノートは最初は付けず、保存したあとに「編集」から付けられます。保存したループは、行を押しても、「▶ 有効化」を押しても、その区間に切り替えて先頭から再生が始まります。行を長押しすると、そのループの編集フォームがその場で開きます。ループが始まると、そのカードのボタンは「ループ OFF」に変わります。「ループ OFF」を押すと、曲は止めずにループだけを止めます（A–Bは残るので、もう一度「▶ 有効化」を押すと同じループを再開できます）。保存したループは曲ごとに分かれています。
  • 保存したループの編集：各ループの「編集」を押すか、行を長押しすると、その場で開始・終了時間と再生倍率（速度）を変更でき、ノートもここで付けたり直したりできます。時間は、初期設定ではキーボードで直接入力できません（キーボードが毎回開かないようにするためです）。時間の欄を押してもキーボードは開かず、「<<< << < > >> >>>」の矢印ボタンと「今」ボタンで合わせます。「1:23.50」のような表記や秒数（例：83.5）で直接入力したいときは、管理画面の「設定」タブの「16. 時間指定入力」をオンにしてください。倍率は大きなプリセットボタン（管理画面の「設定」で選んだ倍率）とフェーダーだけで変えられます。開始・終了時間や倍率を変えると、変更直後にプレイヤーへ反映され、その区間が新しい設定で再生されます（終了時間を変えたときは、終了の少し前＝初期3秒前＝から再生して確認できます）。「保存」で確定します。保存時に設定されていた速度も一緒に記録され、有効化するとその速度で再生されます。再生速度のボタンも同じ倍率の並びで、フェーダーでは0.25〜2.00×の範囲で自由に変えられます。保存したループのリストでは、サイドパネルと同じ並びで、1行目に色ドットとループ名、2行目に倍率タグと「開始時間 〜 終了時間」が表示され、ノートは省略されずに全文が表示されます。ボタン類（有効化／ループ OFF・編集・削除）は右端に縦に並びます。倍率は色付きの丸いタグで表示されます（遅い倍率ほど青く、速い倍率ほど赤くなります）。各ループには、色が重ならないよう自動で割り振った色が少しだけ付き、その色は全体表示（タイムライン）の同じループの色とそろっています。
  • サイドパネル：画面の端に、今の曲の保存ループが色付きのタブで少しだけ顔を出しています（サイドパネル風）。初期は左端で、管理画面の「設定」タブの「17. サイドパネルの表示位置」で右端にも変えられます。端の「🔁」ハンドルをタップするか、画面の中央へスワイプするとパネルが開きます。各ループの▶ボタンで再生でき、ループ再生中のループには赤い■ボタンが出て、押すとループだけが止まります（曲は止まりません）。ループ名をタップすると、その場で名前を変更できます（✓かEnterで保存、✕かEscでやめます）。各ループの「✏️ 編集」はショートカットで、押すとそのループの編集フォームがループリストの中でその場で開きます。パネルは「練習」以外では表示されません。
  • タイムライン：プレイヤー下の色分けバーが全体表示です。保存したループが色付きで並び、幅のある区間には名前も出ます。色付きの区間をタップすると、そのループがそのまま先頭から再生されます。現在のループの開始・終了位置には A／B の旗印が付きます。＋／−でズームでき、ズームに合わせて下の目盛り（30秒・10秒・1秒・0.1秒…）が切り替わります。バーをタップするとその位置へ移動し、ドラッグでも再生位置を動かせます。ページを下にスクロールすると、モード表示が画面の一番上に固定されたまま、その下に動画とタイムラインが小さく固定表示されます。小さいプレイヤーでは現在時刻が大きく表示されるので、ループを作ったり編集したりする途中でも、再生位置と時間が見えたまま作業できます。ループを選ぶ（有効化する）と、タイムラインはそのループの区間に合わせて自動でズームします（ループを解除すると全体表示に戻ります）。ループを選ぶ（有効化・編集）と、そのループの表示は、ほかのループと重なっていても一番手前に出ます。
  • 曲リスト：曲リストは練習画面には出ません。最初に読み込まれる曲（サンプル曲など）は、「曲」モードの「セットリスト」に「曲リスト」というセットリストとして入っています。曲の切り替えはそこで行います：セットリストの中の曲をクリックすると、その曲の再生が始まって練習画面に移ります。プレイヤー上部のセットリスト情報には、いまの曲の前／次の曲名が「曲名 / バンド名」で表示されます。保存ループがある曲には、曲名の横に🔁アイコンと件数が出ます（保存ループが0件の曲には、アイコンも件数も出ません）。
  • 初期に読み込まれるセットリスト：「曲」モードの「セットリスト」タブ上部で、ページを開いたときに読み込まれるセットリストを選べます（初期は自動＝「曲リスト」／最初のセットリスト）。選んだセットリストは先頭に「初期」の印付きで表示され、次に開いたときから先頭の曲で読み込まれ、プレイヤー上部のセットリスト情報に表示される前／次の曲も、そのセットリストの順番になります。各セットリストの「初期に設定」ボタンでも切り替えられます。
  • セットリストにサンプル曲を追加：各セットリストの「中身を編集」を開くと、「サンプル曲をすべて追加（全32曲）」ボタンがあります。押すとサンプル曲がまとめてそのセットリストに入ります（読み込まれていないサンプルは、読み込んでから追加します）。
  • サンプル曲のシャッフル：サンプル曲（16バンド・32曲）は、開くたびにランダムな順番のプレイリストとして並びます。「曲」モードの「セットリスト」タブにある「🔀 シャッフル」を押すたびに並びが新しくシャッフルされ、プレイヤー上部のセットリスト情報に表示される前／次の曲も、その順番になります。元のバンド順（Pink Floyd → The Beatles → … → Green Day）に戻したいときは「バンド順に戻す」を押してください。シャッフルされるのはサンプル曲だけで、自分で追加した曲の並びや、保存したループには影響しません。
  • 自動保存：保存したループ・追加した曲・コメント・最後に開いていた曲と再生速度は、ブラウザの保存領域（localStorage）に自動で保存され、ページを開き直すと復元されます。保存領域はサイトごとに別々なので、このページとGitHub Pages版の間では自動では引き継がれません。引っ越しやバックアップには書き出しファイル（looper-export.txt）を使ってください。ローカルMP3はファイル自体は保存できないので、曲名などの情報だけが残り、再生するにはファイルの再追加が必要です。
  • サンプルデータ：サンプル曲には「サンプル」の表記が付きます（曲リスト・管理画面の曲／全ループ／曲リスト／保存ループリスト内）。管理画面の「設定」タブ（10. サンプルデータ）で、「読み込み時にサンプルデータのロードを次からやめる」にチェックすると、次に開いたときからサンプル曲は自動で読み込まれません。「サンプルデータを追加」ボタンを押すと、あらゆるサンプル（全32曲）をその場で読み込めます（すでにあるサンプルは重複しません）。サンプル曲に付けたループなどは、サンプルを再び追加すると戻ります。
  • YouTubeコメントの時間つき感想（試作）：右側の「保存ループ」カード下部の「💬 YouTubeコメントの時間つき感想（試作）」で「コメントを取り込む」を押すと、今開いているYouTube動画のコメントを公開API（Piped）経由で取得し、「1:23」のような時間が書かれた感想だけを、時間と内容のセットで表示します。時間をタップするとその位置から再生でき、「この時間でループを作る」を押すと、その時間からキャプチャ秒数分のループとして保存され、コメントの内容がそのループのノートに入ります（出典として、コメントの投稿者名もノートに残ります）。一覧の下には出典（YouTubeのコメント／Piped経由）と元の動画へのリンクが表示されます。コメントが取得できない場合や、時間の書かれたコメントが無い場合は、その旨が表示されるだけで、ループや再生など、ほかの機能は今まで通り使えます。取り込んだコメントは保存されず、その場だけの表示です。
  • ホーム画面に追加：管理画面の「設定」タブ（11. ホーム画面に追加）から、このページをホーム画面に追加してアプリのように使えます。ブラウザ側の案内（「Keep your practice setlist one tap away / Install / Not now」）で「Not now」を選んだあとでも、ここからいつでも追加できます。ブラウザが自動のインストール画面を出せる場合はInstallボタンでそのまま追加でき、出せない場合（iPhoneのSafariなど）は、共有ボタン→「ホーム画面に追加」などの手順が表示されます。
  • 管理画面：上部メニューは常時表示です。「ループ」ではループとループセット（タブで切り替え）、「曲」では曲とセットリスト（タブで切り替え）を編集できます。ループ管理では、保存したループを曲をまたいで一覧表示し、検索・再生・編集・削除ができます。ループを集めて「苦手なソロ集」「リフ練習」のようなループセットを作ると、その順番で各ループを指定回数ずつ続けて練習できます（各ループの編集画面の「ループセットに追加」からも入れられます）。曲を集めたセットリストや、曲の名前の編集も曲管理でできます。保存ループリストや全体のデータは書き出しファイルで友達と共有でき、相手は管理画面の「設定」タブ（書き出し・読み込み）から読み込むだけで同じリストが使えます。「設定」タブでは、再生速度の倍率ボタン／ジャンプする秒数／クイックキャプチャの秒数／長押しループの最小時間／微調整ボタンの刻み／終了時間のプレビュー位置／サンプル曲のシャッフル／保存ループの並び順／自動保存の9項目と、削除の確認、サンプルデータの読み込み設定、書き出し・読み込みを変更でき、ホーム画面への追加（アプリとして使う）もここからできます（初期値はいままで通りで、変更は保存されます）。この使い方・解説自体も、「設定」タブの中にあります。
  • 言語：管理画面の「設定」タブ（12. 言語）で「🇯🇵 日本語／🇺🇸 English」を選ぶと、画面表示の言語が切り替わります。初めて開くときは、ブラウザの言語設定に合わせて表示します。機能や保存データは変わりません。
  • つなぎ目：ローカルMP3とDriveの曲は、読み込めた場合にシームレス再生（Web Audio）になり、ループのつなぎ目がほぼ出ません。YouTubeは仕組み上、開始位置を先読みして早めに巻き戻す改善のみで、つなぎ目が少し残ります。
  • 再生できないYouTube動画：動画によっては、YouTube側で埋め込み再生が許可されておらず、このページの中では再生できないものがあります。その場合は、プレイヤーに案内が出ます。「YouTubeで開く」を押すと、YouTubeのページでそのまま再生できます（その動画ではループ練習はできません）。ループ一覧など、ほかの機能はそのまま使えます。

※ Driveの曲は、共有リンクのままではブラウザから直接再生できない場合があります（大きなファイルではGoogle側の確認画面が返ることがあります）。おすすめは「MP3をダウンロード → ローカルMP3で追加」の流れです。① Driveでファイルを開いてMP3をダウンロード、② 「曲」モードの「曲の追加」にある「ローカルMP3」タブでそのファイルを追加、③ そのまま再生・ループ練習。ローカルMP3なら確実に再生できます。詳しい手順は「Drive / MP3 URL」タブの中にも出ています。
※ 保存したループ・追加した曲・コメント・再生速度は、あなたのブラウザの保存領域（localStorage）に自動保存され、次に開いたときに復元されます。他の人と共有されることはなく、公開範囲のような設定もありません。ただし保存領域はサイトごとに別々です（このページとGitHub Pages版では別々に保存されます）。サイト間の引っ越しやバックアップには、書き出しファイル（looper-export.txt）を使ってください。ローカルMP3はファイル自体を保存できないため、曲名などの情報だけが残り、音を再生するにはファイルの再追加が必要です。
